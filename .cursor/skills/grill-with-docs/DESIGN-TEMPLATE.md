# DESIGN.md 模板

`/grill-with-docs` 在品牌视觉规范确认后，惰性创建 `docs/design/DESIGN.md`。

## 产出目标

文档须**完整到可还原品牌板**——即一张可视化总览，包含：


| 品牌板区域 | 文档须给出的内容                                                   |
| ----- | ---------------------------------------------------------- |
| 色板    | 主色 / 辅色 / 第三色 / 中性色 四组 + 每组 8–10 阶色阶（附 HEX）                |
| 语义色   | error / success / warning / info 各 Token + HEX（不含业务状态）        |
| 叠色    | §4 叠色对照表：复用 ≥2 次的叠色须固化 Token + 预计算 HEX                     |
| 字体    | 标题 / 正文 / 标签 三档字体族、样例与使用场景；受限运行时须含实现约束与 fallback 栈         |
| 组件样张  | 见下方「品牌板组件表」——通用 UI 原语逐项覆盖（不含功能页面规格）              |


### 品牌板组件表（通用 UI 原语，§5 须逐项覆盖）

| #   | 原语        | 文档须给出的内容                                               |
| --- | --------- | ------------------------------------------------------ |
| 1   | 按钮变体      | 主 / 次 / 描边 / 文字 / **反色**；各含背景 / 文字 Token、圆角、悬停 / 按下态   |
| 2   | 输入与表单     | 默认 / 聚焦 / 错误态；边框或外发光规则；错误态引用 §2 `semantic-error` Token |
| 3   | 卡片容器      | 圆角、内边距、阴影、背景 Token；**不写**业务内容排列                         |
| 4   | 列表行       | 行高、行间距、分隔方式、选中 / 高亮态；**不写**业务列字段                      |
| 5   | 导航        | 顶栏 / 侧栏 / 底栏 Tab 等主形态与选中态                              |
| 6   | 搜索框       | 输入框与下拉结果的视觉 pattern（无全局搜索须注明跳过）；**不写**业务占位符           |
| 7   | 状态徽章      | 组件形态（padding、圆角、字号）；附 1 条通用样例；**不写**业务状态名               |
| 8   | 图标按钮      | 尺寸、描边粗细、默认 / 悬停 / **选中态** Token（Tab 图标选中态在此定义）         |
| 9   | 空状态       | 插画或图标尺寸、文案字号与颜色、可选 CTA 按钮变体（通用 pattern）               |
| 10  | Loading   | spinner 或骨架屏形态与尺寸（不适用须在文档注明跳过）                         |


正文用叙事性设计说明，含明确规则、Token 名与 HEX、组件行为描述。文首注明 `ui-mode`（`spec-driven` 规范驱动 UI 或 `mockup-driven` 稿驱动 UI）。

**叠色规则：** 复用 ≥2 次的叠色须在 §4 对照表固化；§5 引用 Token 名，禁止裸写 `primary @ N%`。单次不复用的叠色可直接写 HEX。mockup-driven 下页面视觉以 PNG 为准，但叠色对照表仍须可独立画板。

**语义色规则：** error / success / warning / info 须在 §2 定义。§5 输入错误态引用 `semantic-error`；§5 状态徽章只写组件形态与通用样例，不写业务状态名或状态色映射。

**§5 范围规则：** 只写通用 UI 原语（atom/molecule）。禁止：页面名、业务字段布局、功能专属复合组件、领域术语、业务状态名。功能页面：mockup-driven → PNG 稿；spec-driven → 实现规划阶段，不写入 DESIGN.md。

**字体实现规则：** 受限运行时（小程序 / RN / Flutter / 原生 APP）须在 §3 写明加载策略与 fallback 栈。mockup-driven 下 PNG 管视觉，§3 管 Token 与实现边界；稿面字体与实现字体不一致时须分别列出。
