# ① AI Coding 是什么

## 一句话

**AI Coding**：人用自然语言与 AI 编程助手协作，让 AI 阅读、修改、生成代码与项目文件，并由人负责目标、范围与验收的一种软件开发方式。

## 它通常包含什么

- 在 Cursor / Claude Code / Codex 等工具里对话或开 Agent
- AI 读写项目文件、跑命令、解释报错、提出方案
- 人提供上下文（要做什么、别改什么、怎样算好）、审查结果

## 它不是什么

| 容易误会 | 更准确 |
|----------|--------|
| 「AI 全自动做完产品」 | 人仍要定方向与验收；AI 是加速执行 |
| 「只会补全一行代码」 | 现代助手可跨文件改、跑终端、跟流程剧本（Skills） |
| 「不用懂任何工程」 | 越复杂的交付，越需要 Git/协作/验收等常识（见第③章） |

## 和「传统手写代码」的关系

- 不是二选一：多数人是 **AI 起草 + 人审查/补约束**。
- 价值在于：把重复劳动和探索成本压下去；责任与品味仍在人。

## 练习（轻量核对）

**题**：用一句话说，AI Coding 里「人」最不能外包给 AI 的是什么？

**推荐答案**：目标、范围和验收（做成什么样、改哪里、怎样算做完）——这些不定，AI 只能猜。

对用户：题目 + 推荐答案一起给，问是否认同即可。
