# Triage 标签


| 标签                | 跟踪器中的标签           | 含义          |
| ----------------- | ----------------- | ----------- |
| `needs-triage`    | `needs-triage`    | 待评估         |
| `needs-info`      | `needs-info`      | 待报告人反馈      |
| `ready-for-agent` | `ready-for-agent` | 可由 Agent 接手 |
| `ready-for-human` | `ready-for-human` | 待人工处理       |
| `wontfix`         | `wontfix`         | 不处理         |
