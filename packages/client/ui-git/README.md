# @deepseek-ai/dsh-client-ui-git

English | [中文](README.zh.md)

Git panel surface for the Web toolbox **Git** tab: the occupant injected into `conversation.details.git`. The panel follows the Workspace whose `sessionIds` include the current Session, discovers the Git repository root upward from that bound directory, and lists disk-only unstaged and staged working-tree changes, including files inside untracked directories. It does not import `ui-file-editor` internals.

The left column shows two sibling collapsible groups. **CHANGES** holds the current branch (or Git's detached-HEAD description), the unpushed line and **Push** when needed, the commit field, and the **Changed, not staged for commit** / **Ready to commit** lists; that whole body indents 14px under the folder title. **GRAPH** stays pinned at the bottom of the ops column while Changes is open, indents its list 14px under the folder title, and loads fifty commits at a time as its own list scrolls until history is exhausted. When the branch has unpushed commits, a second line under that label shows a plain-language count (or first-push copy) and **Push**; that line is omitted when there is nothing to push. Graph keeps a first-parent trunk on the left; extra parents open a colored side lane and curve back as a node-to-node arc when that branch merges; each row's subject starts after that row's rightmost node or stroke. a later merge that reuses the lane gets a new color. Merge commits use a hollow node. Remote refs keep the `origin/` prefix and render as an orange pill; pills are 14px tall, cap at 80–88px, ellipsize the label, and sit right-aligned on a second line under the subject so they do not cover the author. Hovering a pill opens a fixed GitLens-style card with the full ref, author, relative and absolute time, subject, body, and short hash. Each inner change list keeps its content height and the Changes body scrolls, so a long unstaged list pushes **Ready to commit** below those rows without covering Graph. Unstaged rows expose whole-file stage and discard (discard confirms first); staged rows expose only unstage. Commit requires a non-empty message and a non-empty staged list; the chevron menu offers **Commit & push** (Host runs `git push` after commit, falling back to `-u origin HEAD` when upstream is unset). Drafts are stored per Session in the slot store and survive hiding the Git tab or switching Session; a successful commit clears that Session's draft and shows an inline success hint. Clicking a row loads a disk-only diff preview in the right column and does not open an editor tab. Tracked-text hunks can be staged, unstaged, or discarded (discard confirms); untracked text, binary, and deletion previews are whole-file only. A dirty editor tab blocks discard, stage (whole file, hunk, or **Select all**), and any commit that includes that path; unstage is unrestricted. The guard dialog asks the user to save, discard that edit buffer, or close that tab and does not auto-save.

`apply` injects `gitWorkingTree`, `gitInit`, `gitDiffPreview`, `gitStage`, `gitUnstage`, `gitDiscard`, `gitCommit`, `gitPush`, and `gitLog` closures from `ctx.workspaces`. Product states `git-unavailable` and `not-a-repository` ride the success discriminant and render mutually exclusive overlays; only `not-a-repository` offers **初始化仓库**. A clean repository keeps the commit field with empty change lists. The occupant stays mounted when the Git tab is hidden; it re-reads disk when the tab becomes visible, when the bound Workspace changes, and after a successful init. Write RPCs return the refreshed lists and re-fetch the selected preview when that path remains. It does not poll while the tab stays selected. Ignored paths never appear because Host omits them.

## Model Experience

None, as the Git panel is browser chrome; working-tree lists, branch names, and commit drafts never enter the session log.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **No standalone pull/fetch/branch controls** — the panel does not pull, fetch, amend, or switch branches; optional **Commit & push** pushes the current branch after commit; local unpushed commits show **Push** (`host.gitPush`) on the line under the branch label.
- **Graph hover card has no GitHub link** — the card shows author, times, message, and short hash from `host.gitLog`; it does not resolve a remote HTML URL.
